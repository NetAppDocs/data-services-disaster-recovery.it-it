= Aggiungi cluster locali e Amazon EVS vCenter in NetApp Disaster Recovery
:allow-uri-read: 


[role="lead"]
Dopo aver creato i siti, aggiungi i vCenter cluster per ciascun sito in NetApp Disaster Recovery. Il tipo di sito determina l'accesso che NetApp Disaster Recovery richiede per i vCenters in quel sito. Amazon EVS vCenters e i vCenters on-premises utilizzano le stesse informazioni di connessione e autenticazione.

.Passaggi per aggiungere un vCenter a ciascun sito
. Dall'opzione *Siti*, seleziona *Aggiungi vCenter* per il sito desiderato.
+
image:evs-add-vcenter-1.png["Aggiungi l'opzione vCenter"]

. Nella finestra di dialogo Aggiungi server vCenter, seleziona o fornisci le seguenti informazioni:
+
.. L'agente NetApp Console ospitato nel tuo AWS VPC.
.. L'indirizzo IP o FQDN per il vCenter da aggiungere.
.. Se necessario, cambia la porta con la porta TCP utilizzata dal tuo vCenter server.
.. Il nome utente vCenter per l'account creato in precedenza che verrà utilizzato da NetApp Disaster Recovery per gestire vCenter.




. Se la tua organizzazione utilizza un'autorità di certificazione (CA) esterna o il vCenter Endpoint Certificate Store, deseleziona *Usa certificati autofirmati*. Altrimenti, lascia la casella selezionata.
+
.. Selezionare *Aggiungi*.
+
image:evs-add-vcenter-2-3.png["Finestra di dialogo Aggiungi vCenter"]
